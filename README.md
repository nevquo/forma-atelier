# FORMA Atelier

A complete, responsive premium-service-business concept website created as a NEVQUO portfolio project.

## Pages

- Home
- Work index
- Project case study
- Services
- Studio / About
- Contact

## Run locally

Open `dist/index.html` directly, or serve the `dist` directory with any static web server.

## Notes

- The inquiry form includes client-side validation, loading and error states, a honeypot, a Cloudflare Pages Function, D1 persistence, and unique confirmation references. Follow `CLOUDFLARE-DEPLOYMENT.md` to create and bind the database.
- All business names, project details and statistics are fictional and intentionally labelled as an independent concept project.
- All five original architectural images were generated specifically for this project.

## WordPress adaptation

The semantic HTML, CSS variables and shared components can be transferred into a custom WordPress theme. Create pages for Home, Work, Services, Studio and Contact; model projects with a `project` custom post type; and replace the sample inquiry handler with your selected form solution.
